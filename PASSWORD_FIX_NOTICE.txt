# 密码文件修复通知

## 问题
密码文件在创建时包含了末尾的换行符，导致通过 GUI 点击 DMG 时输入密码提示不正确。

## 原因
```bash
echo "$RANDOM_PASS" > ~/.macos-backup-secrets
```
这种写法会在文件末尾添加换行符 (0x0a)，导致实际密码为:
- 存储的: `hi5w1AaAr1r0f57EhjVhJrhoBONyvQsq\n` (33 字节)
- 实际的: `hi5w1AaAr1r0f57EhjVhJrhoBONyvQsq` (32 字节)

## 解决方案
已使用以下方式修复密码文件:
```bash
echo -n "$PASS" > ~/.macos-backup-secrets
```
使用 `echo -n` 参数可以避免添加换行符。

## 现在状态
✅ 密码文件已修复 (32 字节，无换行符)
✅ GUI 点击 DMG 时现在可以正确输入密码
✅ 命令行挂载已验证成功

## 正确的密码
hi5w1AaAr1r0f57EhjVhJrhoBONyvQsq

## 验证方式
点击 DMG 文件时输入上述密码，应该可以正常挂载。
或者用命令行验证:
```bash
cat ~/.macos-backup-secrets | hdiutil attach -stdinpass backup-20261031-232908.dmg
```
