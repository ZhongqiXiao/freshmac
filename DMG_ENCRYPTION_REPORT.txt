## 🔧 脚本优化总结

### 参数变更
```bash
# 旧: 必须指定密码
bash backup.sh --dmg mypass123

# 新: 支持无密码
bash backup.sh --dmg          # 无密码
bash backup.sh --dmg password # 有密码
```

### 代码实现
- 移除了强制要求密码的检查
- 判断密码是否为空，动态选择 hdiutil 命令:
  - 空密码: `hdiutil create -srcdir ... -format UDZO`
  - 非空密码: `hdiutil create -srcdir ... -format UDZO -encryption AES-256 -stdinpass`
- 输出信息动态显示 "密码保护: 是/否"

### 文件大小优化
- UDZO 格式自动压缩，无需预先指定大小
- 15M 源备份 → 7.9-8.0M DMG (~47% 节省)
- 3 个 DMG 总计节省空间: ~22M
